# G 區實體燈控

Windows 本機 `node server/server.mjs` 經 PowerShell SerialPort 控制 COM3，無需 Python。
燈控子程序使用 `-ExecutionPolicy Bypass`，僅限該程序，經使用者批准；不修改任何持久或全域執行原則。
協定為交接包 BPR1：115200 8N1、DTR/RTS 關閉，CRC16-CCITT-FALSE。
紅／綠／藍亮度 50%，200ms 漸變；以序號與九路 PWM 回報確認結果。
綠轉藍例外使用 900ms 漸變。自動展演預送約 0.5 秒（前言、通關、結束）；手動操作不預送。串口仍逐次開啟，因此預送是補償，並非硬體零延遲保證。
藍光為本機橋接新增效果，使用 BPR1 的 B 通道；未修改原交接包或 ESP 韌體。

## 規則
- welcome：開場維持藍光，語音開始也不轉紅。
- intro：進入「意外發生每一秒都是關鍵」畫面轉紅。
- 逃生動線待機及展示方向：紅；通關：綠。
- 結語播放期間：綠。
- 手動結束／停止展演、自動展演完成，或非自動展演的結語語音播完：回藍。

只開一個主螢幕控制頁，Pad 透過主螢幕同步，不直接控制串口。
同時間只執行一筆串口操作；等待期間只保留最新目標，重複狀態不重送。
失敗會在伺服器記錄 FAILED，避免持續重試；檢查接線後切換狀態或重啟伺服器重試。
不要同時執行手動 BAT 測試，避免 COM3 被占用。

可用環境變數 G_LIGHT_PORT 改埠；G_LIGHT_DISABLED=1 停用。
本機區網展示用途，WebSocket role 不是身分驗證，不應公開到網際網路。
連線中斷／程式強制結束時，ESP 保持最後輸出，不保證自動關燈。
結語保持綠光直到展演結束。手動維護仍保留 off 指令；重新整理主螢幕以載入新規則。
沒有修改或重刷 ESP 韌體。GitHub Pages 本身不能開啟 USB 串口。
